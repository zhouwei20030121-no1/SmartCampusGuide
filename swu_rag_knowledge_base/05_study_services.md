# 5. 学习服务库

用途：存放与学习、自习、课程、考试、图书馆、教室相关的信息。描述用户怎么使用这些地方。

### 学习服务：图书馆自习与文献借阅服务

entity_id: service_study_lib
type: study_service
related_locations: 中心图书馆, 弘文图书馆

服务说明：
图书馆是西南大学最主要的学习与自习场所。官方图书馆简介显示，全校现有阅览座位校本部6000余个，落成于2013年的中心图书馆是学习中心。学生可以使用校园卡刷卡入馆，享受图书借阅、阅览自习、文献检索、电子资源使用等服务。具体开放时间、座位预约和访客入馆规则需以图书馆官方最新通知为准。

常见问题：
- Q：图书馆适合自习吗？
  A：适合。图书馆是校园主要自习和文献检索场所，具体开放时间、座位预约和入馆规则需以图书馆官方通知为准。
- Q：图书馆现在开门吗？
  A：图书馆开放时间可能随学期、节假日、考试周 and 临时安排调整。请查看图书馆官方通知或 APP 实时服务信息，我不能仅凭固定时间作保证。

### 学习服务：公共教学区与空教室自习

entity_id: service_study_classroom
type: study_service
related_locations: 教学区, 敬德楼, 荟文楼, 兆畦楼

服务说明：
西南大学公共教学区由多个教学楼、公共教室和实验空间组成。在没有课程占用的时间段，部分公共教室可供学生进行日常自习。学生在使用公共教室自习时，应当自觉维护课室秩序，不踩踏座椅，离开时带走个人垃圾。具体教室开放时间、排课信息及临时封楼通知，请以学校教务处或各楼栋铭牌、通告为准。

常见问题：
- Q：我想找附近能学习的地方。
  A：优先推荐图书馆；如果你离学院楼或教学楼更近，也可以查看教学楼空教室或学院学习空间。具体开放状态、空座和预约规则需以实时服务信息为准。
- Q：第一天去教室上课要注意什么？
  A：建议至少提前规划路线并预留找楼、找教室和等电梯时间。具体出发时间需根据宿舍到教学楼距离、天气和人流判断。

### 学习服务：第25教学楼（明德楼）专业学习与教室寻找

entity_id: service_study_college_space
type: study_service
related_locations: 第25教学楼

服务说明：
第25教学楼（明德楼）是信息类与工科相关专业教学办公的重要楼宇，主要供计算机与信息科学学院软件学院、材料与能源学院、电子信息工程学院等使用。该大楼涵盖了学院办公室、专业教学课室、报告厅和学术交流空间。专业课上课或前往学院办理事务时，需根据课表及大楼的层级索引图寻找具体教室或办公室，切勿编造位置。

常见问题：
- Q：第25教学楼是干什么的？
  A：第25教学楼又名明德楼，官方资料显示现为计算机与信息科学学院软件学院、材料与能源学院、电子信息工程学院等单位使用，承担教学、办公、报告厅活动等功能。
- Q：第25教学楼是计算机学院吗？
  A：它与计算机与信息科学学院软件学院相关，但官方资料也显示材料与能源学院、电子信息工程学院等单位使用，不能简单理解为只属于一个学院。
