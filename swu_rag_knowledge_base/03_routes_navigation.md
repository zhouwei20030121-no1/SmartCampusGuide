# 3. 校园路线库

用途：专门存放路线规划、参观路线、步行动线。


---

### 路线：新生校园熟悉路线

entity_id: route_freshman_orientation
type: route
起点: 宿舍区域或新生当前定位点
终点: 宿舍区域或图书馆
途经点: 食堂区域，校车站点，教学区，图书馆，第25教学楼，校园中心区域
推荐人群: 本科新生，研究生新生，陪同家长
预计耗时: 约1.5至2.5小时；具体需以路线长度、天气和停留时间为准。

路线说明:
建议先从宿舍出发，找到最近食堂和校车站点，再前往主要教学区和图书馆，最后确认到第25教学楼等专业相关地点的路线。若用户属于计算机与信息科学学院，应重点加入第25教学楼。

注意事项:
不要编造精确距离；宿舍楼不同路线差异很大；需以校内地图或现场路牌为准。

用户可能问法:
- 新生第一天应该先熟悉哪些地方？
- 我刚到西大，怎么快速认识校园？
- 计算机学院新生应该先去哪里？

### 路线：校史文化参观路线

entity_id: route_history_culture
type: route
起点: 二号门或校园中心区域
终点: 图书馆或博物馆/校史馆
途经点: 二号门，南樟林，图书馆，博物馆/校史馆，校园文化景观
推荐人群: 游客，校友，新生班级，研学团队
预计耗时: 约2至3小时；若进入校史馆详细参观，需按开放时间和预约安排调整。

路线说明:
从二号门进入后先讲解“学行门”和大学精神，再前往南樟林感受环境文化，随后到图书馆了解学习空间，最后参观校史馆或博物馆相关展区。

注意事项:
校史馆开放时间、预约讲解和拍摄要求需以官方通知为准；馆内需保持安静，不触摸展品。

用户可能问法:
- 西南大学校史文化怎么参观？
- 我想带朋友了解西大历史，怎么走？
- 校友返校适合走哪条路线？

### 路线：二号门到图书馆路线

entity_id: route_gate2_to_library
type: route
起点: 二号门 / 学行门
终点: 图书馆
途经点: 南樟林，校园中心区域
推荐人群: 游客，新生，从二号门入校人员
预计耗时: 具体步行时间需由 APP 地图实时测算。

路线说明:
从二号门进入后，可先在南樟林短暂停留，再沿校内主路或 APP 推荐路线前往图书馆。具体道路名称和分叉口需以地图和路牌为准。

注意事项:
二号门通行规则、图书馆开放状态和路线封闭情况需实时确认。

用户可能问法:
- 二号门到图书馆怎么走？
- 从学行门进来怎么去图书馆？
- 二号门附近有什么顺路景点？

### 路线：图书馆到第25教学楼路线

entity_id: route_library_to_building25
type: route
起点: 图书馆
终点: 第25教学楼 / 明德楼
途经点: 校园中心区域，教学区道路
推荐人群: 计算机与信息科学学院学生，参加讲座人员，新生
预计耗时: 需由 APP 地图实时测算。

路线说明:
从图书馆出发，以第25教学楼或明德楼为终点导航。到楼下后核对“明德楼（第25教学楼）”标识。官方资料显示该楼为计算机与信息科学学院软件学院等单位使用。([西南大学][5])

注意事项:
第25教学楼楼层较多，用户还需确认教室号或办公室号。

用户可能问法:
- 图书馆到计算机学院怎么走？
- 图书馆去25教远吗？
- 明德楼在哪里？

### 路线：一小时校园快速参观路线

entity_id: route_one_hour_tour
type: route
起点: 南门、二号门或用户当前位置
终点: 校园中心区域或原入口
途经点: 最近校门，樟树林，图书馆，校园中心区域，教学区外观
推荐人群: 游客，短暂停留校友，陪同家长
预计耗时: 约1小时。

路线说明:
选择最近入口进入，优先参观一个校门文化点、一个自然景观点、一个学习空间外观和一个教学区外观。若从二号门进入，建议加入南樟林；若从南门进入，建议先到图书馆或光华楼周边。

注意事项:
不建议在一小时内跨越过多片区；校园较大，应控制停留点数量。

用户可能问法:
- 我只有一小时，西大怎么逛？
- 带朋友快速参观西南大学去哪？
- 西大短线打卡路线怎么安排？

### 路线：半日校园深度游路线

entity_id: route_half_day_tour
type: route
起点: 南门或二号门
终点: 食堂区域或原入口
途经点: 校门文化点，樟树林，图书馆，博物馆/校史馆，教学区，第25教学楼，食堂区域，操场/体育场
推荐人群: 游客，校友，新生家长，研学团队
预计耗时: 约3至5小时；若进入场馆或用餐，耗时更长。

路线说明:
先参观校门与环境文化，再进入图书馆周边和校史文化场馆，随后走教学区和学院楼，最后体验食堂、操场等生活场景。

注意事项:
博物馆/校史馆需确认开放时间；食堂就餐和图书馆入馆需遵守现场规定；夏季注意防暑。

用户可能问法:
- 西南大学半日游怎么安排？
- 我想深度参观西大，路线怎么走？
- 校友返校半天可以看哪些地方？

### 路线：校园拍照打卡路线

entity_id: route_photo_spots
type: route
起点: 二号门或南门
终点: 图书馆或樟树林
途经点: 校门，南樟林，图书馆外观，校园中心区域，操场/体育场，博物馆/校史馆外观
推荐人群: 游客，毕业生，校友，新生，摄影爱好者
预计耗时: 约1.5至3小时。

路线说明:
建议先拍校门，再拍樟树林自然场景，随后拍图书馆外观和校园中心区域，最后根据时间选择操场或校史馆外观。

注意事项:
馆内拍照规则需遵守官方要求；不使用闪光灯、自拍杆或脚架的场所应严格执行；不进入宿舍等生活私密区域拍摄。

用户可能问法:
- 西南大学哪里适合拍照？
- 西大毕业照去哪拍？
