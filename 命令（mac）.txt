启动：

brew services start redis

cd 3_Backend_Java && mvn spring-boot:run &

cd 4_AIService_Python && HF_ENDPOINT=https://hf-mirror.com .venv/bin/uvicorn main:app --reload --port 5000 &

cd 2_AdminWeb_Vue && npm run dev &

# 启动反向代理和内网穿透（必须在上方的 Java/Python 启动后执行）
caddy start --config Caddyfile
ngrok http --domain=genna-boldhearted-dewily.ngrok-free.dev 8081 &


关闭：

brew services stop redis ; pkill -f "java" ; pkill -f "uvicorn" ; pkill -f "vite" ; caddy stop ; pkill -f "ngrok"
